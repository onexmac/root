# cuadrillas

Tablero de cuadrillas por maestro de obra (Ovet, Gemelo, Carreño, Joel, Libre). Sitio estático: un solo `index.html`, sin build.

- Datos: `data/cuadrillas.json` (de Lista_Personal.xlsx, Hoja1). Los mismos datos van embebidos en `index.html`.
- Estilo: AD Visual (Figma `gAMndOnwTBgC6nZnjY6bgT`), claro y oscuro.
- Estado: se guarda en el navegador (localStorage `cuadrillas-v2`).

## Vercel
Proyecto `cuadrillas`, repo `onexmac/root`, Root Directory `cuadrillas`, Framework Preset **Other**, sin build command ni output directory.
