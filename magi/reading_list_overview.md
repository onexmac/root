---

## Why This File Exists

The Human Instrumentality Project's analytical apparatus is non-trivial only because of the reading substrate the seats and deep companion documents rest on. This is the Napoleon-family principle named explicitly across multiple seats and deep documents (especially `cassettiera_della_corsica.md`): **operational excellence depends on framework inventory loaded through serious reading; without the substrate, the surface methods become aesthetic.**

This file maps the reading substrate to the seats it grounds. The map is not exhaustive; it captures the most operationally relevant works for each seat. The maintenance discipline (Science / `nerv_science.md`) is to keep this file current as the substrate evolves.

## Maintenance Discipline

This file is maintained by Science (`nerv_science.md`). Updates required when:
- A new author is added to a seat's substrate
- A new deep companion document is produced
- A seat's reading is refactored (as in the v3.0 → v4.0 transition)
- An author is promoted from UN-tier to seat or demoted from seat to UN-tier
- Author Brief skill produces a substantial brief that warrants reading-list integration

Outdated entries are removed during periodic maintenance. The file is designed to be useful as an operational reference, not as comprehensive archive.
