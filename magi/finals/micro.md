# Micro — execution reference

**Scope warning.** This file is *reference*, not instinct. It records what verified numbers imply
about execution. It cannot substitute for mechanical skill or pattern recognition. Where an entry is
`[I]`, it is reasoning from a number — treat it as a hypothesis to test in-game, not doctrine.

Most of this file is currently thin. It fills in from debriefs and from the weapon/class data still
missing in `numbers.md`.

---

## Cash box handling `[V]`

- **No speed penalty.** Sprint normally while carrying.
- **Weapons, gadgets, and most specializations are locked out**; using one drops the box.
- **Evasive Dash works while carrying** — and a small set of other movement abilities.
- **Throwing deals 50 damage** on impact. A thrown box is a real, if situational, weapon.
- **Throw-forward tech:** throw the box ahead while sprinting, then run onto it. This buys a free
  window to reload or place a gadget *without losing ground*. The single highest-value piece of
  micro in this file.
- **Throwing into a station from range** starts the cashout marginally sooner — useful when you're
  contesting the last seconds of a timer.
- The box drops if you're **glitched** (Glitch Grenade/Trap) or **Winch Claw stunned** — so a
  carrier under a Glitch effect is disarmed of the objective, not just of gadgets.

## Statue handling `[V]`

- Manual revive is **4 seconds**, held.
- **Enemies cannot pick up your statues.** A statue camp is an angle problem, not a hard denial.
- **You can carry a statue.** Default to dragging it out of line of sight and reviving there —
  most failed revives fail because they were attempted where the player died, not because the
  revive was impossible.

## Terminal awareness `[V]` → `[I]`

A steal is **7 seconds** (6 in the final). `[V]` Practically: `[I]`

- Never leave the terminal unwatched for 7 seconds, in any circumstance, for any fight.
- Conversely, when attacking, you are not looking for a team wipe — you are looking for a **7-second
  window**. That reframes attacking a cashout from "win the fight" to "create one distraction."
- A single unaccounted-for enemy is sufficient threat to lose a cashout.

## Round-one vault timing `[V]` → `[I]`

Vault windup is 15s, opening is 20s. `[I]` That's a 35-second window from spawn in which nobody has
a box and every team's position is predictable. Contesting a vault *as it opens* is often better
than contesting the carrier afterwards — the box appears at a known place and time.
