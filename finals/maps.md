# Maps — STUB

**Nothing verified yet. Do not give map-specific advice from this file until it has content.**

Map knowledge is one of the largest gaps between competent and ranked-strong play, and unlike
mechanical skill it is fully writable — cashout station positions, defensible geometry, approach
lanes, and rotation timings are all facts that can live in a file and be read deterministically.

It is deliberately empty rather than guessed. Fabricated callouts would be worse than none.

## What goes here, per map

- Cashout station positions and which are defensible vs indefensible
- Vault locations and rotation time between them
- For each station: approach lanes, verticality (what can be broken to close a lane), and the
  single best defensive setup
- Rotation timings between the two active stations
- Known destruction tech — which floors/walls change a fight when removed

## How to fill it

Two sources, in order of reliability:

1. **Commander's own play.** Most of this is not documented anywhere useful, and lived knowledge of
   what ranked lobbies actually punish beats any wiki. Describe a station after a match — where you
   set up, where they came from, what worked — and it gets written down.
2. Community/competitive resources, for station and vault positions.

Suggested per-map template:

```
## <Map name>
### Station: <location>
- Approaches: <list>
- Verticality: <what's above/below, what can be cut>
- Best setup: <where the three players sit>
- Fails when: <the known way this defense loses>
```
